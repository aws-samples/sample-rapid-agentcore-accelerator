# Code of Conduct

This project has adopted the [Amazon Open Source Code of Conduct](https://aws.github.io/code-of-conduct).

It applies to everyone who participates in this repository — maintainers, contributors, and anyone opening an issue or a pull request — and it applies in every project space, including issues, pull requests, code review comments, and commit messages.

## Reporting

If you experience or witness behaviour that violates the code of conduct, report it to **opensource-codeofconduct@amazon.com**. Reports are handled confidentially.

For questions about the code of conduct itself, see the [Code of Conduct FAQ](https://aws.github.io/code-of-conduct-faq), or contact the same address.

To report a suspected security vulnerability, use the [AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/) instead — see [CONTRIBUTING.md](CONTRIBUTING.md).
