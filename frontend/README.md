# Chat Frontend

A ChatGPT-style web UI for the agents in this repository, built with [Next.js](https://nextjs.org/), [shadcn/ui](https://ui.shadcn.com/), [AI Elements](https://ai-sdk.dev/elements), and the [AI SDK](https://ai-sdk.dev/). It streams each answer as it is generated, shows the agent's reasoning in a collapsible panel, and renders every tool call as a card with its status, parameters, and result.

Which deployment mode serves it, and how users sign in, is covered in [docs/frontend.md](../docs/frontend.md).

## Run it locally

From the repository root:

```bash
make ui     # http://localhost:3000
```

With no configuration, `make ui` offers every agent in `.rapid/outputs.json` (written by `make deploy`) and invokes them with your AWS credentials. To talk to an agent running on your machine instead, copy `local/.env.example` to `local/.env` and set `LOCAL_AGENT_URL`:

```bash
make docker-run AGENT=customer-support          # terminal 1: agent on :8080
echo 'LOCAL_AGENT_URL=http://localhost:8080' > frontend/local/.env
make ui                                         # terminal 2
```

## How it works

```text
Browser (useChat) ── POST /api/chat ──► Next.js route handler ── InvokeAgentRuntime (SigV4) ──► AgentCore Runtime
        ▲                                     │                    or HTTP to LOCAL_AGENT_URL
        └──── AI SDK UI message stream ◄──────┴── Strands SSE events, mapped by src/lib/strands-to-ui.ts
```

- The agent keeps the conversation in its AgentCore session, so the browser sends only the newest message. The chat ID is the runtime session ID.
- `src/lib/strands-to-ui.ts` translates the events emitted by `agent/{name}/src/utils/sse.py` — reasoning deltas, text deltas, tool input, tool results — into AI SDK stream parts. Tools are rendered as dynamic tools, so the UI needs no knowledge of an agent's tool set.
- Chat history for the sidebar is kept in the browser's `localStorage`.

## Layout

```text
src/app/page.tsx                  Chat page
src/app/api/chat/route.ts         Invokes the agent and streams the response
src/app/api/session/route.ts      Signed-in user and available agents
src/app/api/auth/*                Cognito OAuth code flow (AUTH_MODE=app only)
src/app/api/health/route.ts       ALB health check
src/proxy.ts                      Redirects to sign-in (AUTH_MODE=app only)
src/lib/agentcore.ts              AgentCore / local agent invocation, SSE reader
src/lib/strands-to-ui.ts          Strands event → UI stream mapping
src/lib/auth.ts                   ALB header and Cognito ID token verification
src/components/chat-app.tsx       Sidebar, header, agent picker
src/components/chat-view.tsx      Messages, reasoning, tool cards, prompt input
src/components/ai-elements/       Generated by the ai-elements CLI
src/components/ui/                Generated by the shadcn CLI
local/run_local.sh                Backs `make ui`
```

`src/components/ui/` and `src/components/ai-elements/` are generated; add or update them with `npx shadcn@latest add <name>` and `npx ai-elements@latest add <name>` rather than editing them by hand.

## Environment variables

Set by CDK in deployed modes, or by `local/run_local.sh` and `local/.env` locally.

| Variable | Purpose |
|---|---|
| `AGENT_REGISTRY` | JSON map of agent name → runtime ARN; set when several agents are configured |
| `AGENTCORE_RUNTIME_ARN` | Runtime ARN when only one agent is configured |
| `LOCAL_AGENT_URL` | Talk to a local agent over HTTP instead of AgentCore Runtime |
| `AWS_REGION` | Region of the AgentCore Runtime |
| `AUTH_MODE` | `none` (default), `alb` (ALB-enforced Cognito), or `app` (this app runs the OAuth flow) |
| `PUBLIC_URL` | The URL users reach the app at; used for OAuth redirects and sign-out |
| `COGNITO_USER_POOL_ID`, `COGNITO_CLIENT_ID`, `COGNITO_DOMAIN` | Cognito settings for sign-in and sign-out |

## Develop and verify

Node.js 22 (20.9 minimum).

```bash
cd frontend
npm ci
npm run dev          # http://localhost:3000; same env vars as above
npm run lint
npm run typecheck
npm test             # Strands → UI stream mapping
npm run build
```

To exercise the image that is deployed to Fargate:

```bash
cd frontend
docker build --platform linux/arm64 -t rapid-chat-frontend .
docker run --rm -p 3000:3000 --add-host=host.docker.internal:host-gateway \
  -e LOCAL_AGENT_URL=http://host.docker.internal:8080 rapid-chat-frontend
```
