# Approved Software Catalog

## Development Tools

### IDEs & Editors
- **VS Code** — Free, approved for all employees. Install from Software Center or https://code.visualstudio.com
- **IntelliJ IDEA** — Licensed for Engineering teams. Request via IT ticket (category: software).
- **PyCharm Professional** — Licensed for Data Science team. Request via IT ticket.

### Version Control
- **Git** — Pre-installed on all developer machines. Use GitHub Enterprise at github.acmecorp.com.
- **GitHub Desktop** — Approved. Download from Software Center.

### Containerization
- **Docker Desktop** — Approved for Engineering. Requires license acknowledgment form (IT-FORM-042).
- **Podman** — Approved alternative, no license needed.

## Communication & Collaboration

- **Slack** — Corporate messaging. All employees have access. Desktop app in Software Center.
- **Zoom** — Video conferencing. Licensed for all employees.
- **Microsoft Teams** — Available but Slack is preferred for internal communication.
- **Confluence** — Wiki and documentation. Access at confluence.acmecorp.com.
- **Jira** — Project tracking. Access at jira.acmecorp.com.

## Productivity

- **Microsoft 365** — Full suite (Word, Excel, PowerPoint, Outlook). Pre-installed.
- **Adobe Acrobat Reader** — PDF viewing. Pre-installed.
- **Adobe Creative Cloud** — Licensed for Design team only. Request via IT ticket.
- **1Password** — Corporate password manager. All employees must use this for work credentials.

## Cloud & Infrastructure

- **AWS CLI** — Approved. Install via `brew install awscli` (Mac) or Software Center (Windows). After installation, run `aws --version` to confirm the version meets your organization's minimum requirements.
- **Terraform** — Approved for Infrastructure team.
- **kubectl** — Approved for teams with Kubernetes access.

## Prohibited Software

The following categories are NOT approved for corporate devices:
- Personal VPN services (NordVPN, ExpressVPN, etc.) — conflicts with corporate VPN
- Torrent clients
- Unauthorized remote access tools (TeamViewer personal, AnyDesk)
- Cryptocurrency mining software
- Unlicensed commercial software

## How to Request New Software

1. Check if it's already in the Software Center
2. If not listed, submit an IT ticket with category "software"
3. Include: software name, business justification, number of licenses needed
4. Security review takes 3-5 business days for new software approvals
